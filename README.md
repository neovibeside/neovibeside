### just neovibeside, writing code 👋

I build mobile apps, mostly in Flutter and Dart, and switch to React Native with TypeScript when a project is already committed to it. The part I actually care about is what people touch: transitions that don't stutter, lists that hold 60fps, screens that still work when the network drops. Firebase handles the backend chores, and I lean offline-first on anything that gets used on a commute.

- 🔭 Tuning a Flutter feed so it stays at 60fps on a three-year-old Android phone.
- happier in a terminal than in an IDE
- shipping small and often
